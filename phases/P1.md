## P1.3 `lib/zones.ts`

**Files:** `lib/zones.ts`, `app/globals.css` (append).

- `export const ZONES: Zone[]` — the five rows of `SPEC.md` §5, exact hexes.
- `export const SECTION_ZONE: Record<string, ZoneId>` for `/`, and the case-study sequence per `SPEC.md` §5.
- `export function bgAt(pageY): [number, number, number]` (sRGB channels 0–1) / `metersAt(pageY): number` / `fxAt(pageY): [number, number, number, number]` (rays, caustics, snow, glow, each 0–1) — pure functions over a module-local section list. Export `setSectionOffsets(offsets)`; `lib/layout.ts` (P2.1) calls it after every `measure()`. Until then the list is empty and the functions return the `surface` row. Do **not** import `lib/layout.ts` here (it does not exist yet) and do not touch `window`/`document` in this file — `tsx scripts/contrast.ts` imports it in Node.
- Append `[data-zone="<id>"] { --text: …; --accent: …; --bg-top: …; --bg-bot: … }` for all five zones to `globals.css`.

Do not invent a sixth zone. Do not hard-switch: gaps use `smoothstep`.

**Done:** `npx tsx scripts/contrast.ts` passes all five zones (this is the first time the gate runs contrast).
