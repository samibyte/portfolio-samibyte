# P7 — Launch

**Goal:** every **A** check green, every **U** item handed to the owner in writing.
**Read:** `SPEC.md` §1; `skills/ocean-qa-gate/SKILL.md`.
**Exit:** `STRICT=1 npm run gate` passes; `qa/REPORT.md` lists a pass/fail per constraint and every open **U** item.

## P7.1 Resolve content slots

**Files:** `CONTENT.md`, `lib/content.ts`, `lib/projects.ts`.
Every `[USER: …]` becomes either a real, verified value or is deleted with the field omitted. Confirm: email address, final domain, resume URL, any stack item the owner cannot defend in an interview. Do not invent a metric to fill a slot.
**Done:** `npx tsx scripts/check-content.ts --strict` (or `npm run check:content -- --strict`) exits 0.

## P7.2 SEO surface

**Files:** `app/sitemap.ts`, `app/robots.ts`, `app/layout.tsx`, `app/icon.svg`.
`sitemap.ts` from a single `SITE_URL` constant; `robots.ts` allows all and points at the sitemap; JSON-LD `Person` (name, jobTitle, url, sameAs — the three verified profile URLs only: GitHub, LinkedIn, X). `metadataBase` set from `NEXT_PUBLIC_SITE_URL`. Add a minimal two-colour wave mark as `app/icon.svg` (no text, drawn from the zone palette) and delete `app/favicon.ico` so Next serves it.
**Done:** `/sitemap.xml` and `/robots.txt` return 200; the JSON-LD block validates.

## P7.3 Deploy

**Files:** `README.md` (deploy notes only).
Vercel project, Node 22, env from `SPEC`/`.env.example`. **Do not** claim a deployed URL you have not opened. Record the real URL in `qa/REPORT.md`, or write `BLOCKED (needs owner account)`.
**Done:** either a URL that returns 200, or a written blocker.

## P7.4 Evidence report

**Files:** `qa/REPORT.md`.
One row per constraint: ID · how verified · artifact path · result · date. Then a **U** section listing exactly what the owner must personally check (real-laptop fps, real phone, font choice, factual claims). Mark each `OPEN` or `CLOSED by owner`.
A constraint with no artifact is `FAIL`, never "passed (by inspection)".
**Done:** all **A** rows PASS; every **U** row present and OPEN.

## P7.5 Final gate

**Files:** none.
`STRICT=1 npm run gate` + `npx playwright test` + `npm run lh`. Paste the last 20 lines of each into `qa/REPORT.md`.
**Done:** `GATE: PASS` and the report is committed. Stop — no post-launch features.
