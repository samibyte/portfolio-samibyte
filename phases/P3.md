# P3 — Depth

**Goal:** five visually distinct zones, a near-black end, and mechanically proven contrast.
**Read:** `SPEC.md` §5, §6.1, §9; `skills/ocean-shader/SKILL.md`; `skills/ocean-a11y-contrast/SKILL.md`.
**Exit:** `contrast.ts` passes; `tests/c2` and `tests/c4` pass; the page bottom is near-black.

Add exactly **one** layer per task. After each layer, toggle it via `uFx` and screenshot both states. A layer that cannot be shown to change the image is not done.

## P3.1 Contrast script

**Files:** `scripts/contrast.ts`.
The script ships with the kit; **verify it, do not rewrite it**. For each zone it checks text vs `bgTop`, text vs `bgBot`, and — for light-text zones only — text vs each background with **+0.06** added to the background luminance (the maximum effect lift allowed by `SPEC.md` §5). Gates 4.5:1 body and 3:1 for `--text` used as the focus ring. Accent is advisory (`warn`) and never fails the build. One compact line per zone. Exit 1 on any body failure.
**Done:** `npx tsx scripts/contrast.ts` prints five `PASS` lines and exits 0.

## P3.2 Caustics and god rays

**Files:** `components/ocean/shader.ts`.
Layer 2 caustics multiply only and are strongest just below the surface, fading with depth (`vUv.y`, 1 at the top of the screen). Layer 3 rays fade by `uFx.x`. No screen-space bloom.
**Done:** toggling `uFx.y` and `uFx.x` each visibly changes the image; 4× CPU throttle still renders.

## P3.3 Marine snow

**Files:** `components/ocean/shader.ts`.
Layer 4. Hash-grid, two parallax layers, count `uFx.z × T.snowMax`, active only when `uFx.z > 0.01`. Colour is `text`-adjacent, never pure white (pure white would raise local luminance past the C4 allowance).
**Done:** snow is absent in surface, faint in sunlight (`uFx.z = .1`), and strongest in midnight/abyss (`SPEC.md` §5).

## P3.4 Abyss glow

**Files:** `components/ocean/shader.ts`.
Layer 5. Cool `#35e0c2`, count `uFx.w × T.glowMax`, soft pulse. `#ff9f43` is reserved for the contact lantern — do not use it here.
**Done:** glow appears only past `depth > 0.8`; it never lifts the background more than 0.06 luminance.

## P3.5 Plunge bubbles

**Files:** `components/ocean/shader.ts`.
Layer 6. ≤ 24 bubbles, analytic from `hash(float(i))`, driven by `uPlunge` in seconds, off when `uPlunge < 0`. Constant loop bound with an early `break`.
**Done:** one plunge on first scroll, gone within `T.plungeDuration`; no second plunge on scroll back up and down.

## P3.6 Depth verification

**Files:** `tests/c2.spec.ts`, `tests/c4.spec.ts`.

`tests/c2.spec.ts` — scroll to the document end, hide all text (`[data-zone] * { color: transparent !important }`), screenshot, decode: mean luminance < 0.05 **and** mean blue > mean red.
`tests/c4.spec.ts` — for each `[data-zone]` section, for each text-bearing element: read `color` and font size from `getComputedStyle`, make the text transparent, screenshot the element box, then take the worst-case background luminance (p95 behind light text, p5 behind dark text) and assert ≥ 4.5 (≥ 3 for large text). Sample at scroll steps of 50 vh.
**Done:** both specs pass at 1280×720 and 390×844.

## P3.7 Zone text polish

**Files:** `app/globals.css`, `lib/zones.ts`.
Confirm every section's `data-zone` matches `SPEC.md` §5, gaps contain no text, and the transition band between zones is `T.gapVh` tall. Fix any element inheriting the previous zone's colour.
**Done:** `npm run gate` passes; a Node check samples `bgAt(pageY)` every 8 px across each gap and asserts consecutive samples differ by < 0.02 in each normalized (0–1) channel (a smoothstep, not a seam); no text node sits inside a gap. Do not judge a screenshot.
