## P0.1 Scaffold the app at the repo root

**Files:** everything `create-next-app` writes (repo root).

The kit's own files make the repo non-empty, and `create-next-app` refuses any directory whose contents are not on its small allowlist (`AGENTS.md`, `README.md`, `SPEC.md`, `phases/` all count). **Never delete kit files to work around it.** Scaffold in `/tmp`, then copy the generated project in without overwriting anything:

```bash
rm -rf /tmp/scaffold && mkdir -p /tmp/scaffold
npx create-next-app@latest /tmp/scaffold --ts --tailwind --eslint --app --no-src-dir \
  --import-alias "@/*" --use-npm --no-cache-components --no-agents-md \
  --no-react-compiler --no-agent-feedback --disable-git --yes
(cd /tmp/scaffold && tar --exclude=.git --exclude=README.md --exclude=node_modules --exclude=.next -cf - .) \
  | tar -xf - -C .
npm ci
```

`--no-agents-md` is mandatory: the default template writes its own `AGENTS.md` and would overwrite ours. `--no-cache-components` keeps caching semantics simple. `--no-react-compiler` stops the template installing `babel-plugin-react-compiler` (we do not use it; `--yes` otherwise reuses saved preferences for this flag). `--disable-git` because P0.4 owns git. The `tar` step keeps the kit's `README.md`; it copies `package-lock.json` but not `node_modules`, so `npm ci` installs a clean tree.

Delete the template assets (`public/next.svg`, `vercel.svg`, `file.svg`, `globe.svg`, `window.svg`). Leave `app/page.tsx` and `app/favicon.ico` in place for now — P1.18 owns the home page and P7.2 replaces the favicon with `app/icon.svg`.

**Done:** `next` 16.4.x in `package.json`; `app/`, `public/`, `eslint.config.mjs`, `next.config.ts`, `tsconfig.json` present; `npm run build` passes; `AGENTS.md`, `README.md`, `SPEC.md` byte-identical to the kit; `npx create-next-app@16.4.6 --help` confirms every flag above exists.

## P0.5 Tokens, zones CSS, fallback gradient

**Files:** `app/globals.css`.

- Line 1: `@import "tailwindcss";`
- `:root` holds only **static** tokens: `--text --accent --bg-top --bg-bot --panel --ring`, the type scale, and `--vh: 1vh` as the pre-hydration fallback. JS (P2.3) overwrites `--vh` with `innerHeight * 0.01 + 'px'`, so `calc(var(--vh) * 100)` is the exact viewport height after load. Never `--bob/--glow/--mx` here (they are per-frame and element-local, `SPEC.md` §3.9).
- `@media (prefers-reduced-motion: reduce)` → `* { animation: none; transition: none; }`.
- Static fallback: `body` paints a vertical gradient from `--bg-top` to `--bg-bot`. Before hydration this is the whole background, so it must already look right.
- `:focus-visible { outline: 2px solid var(--text); outline-offset: 2px; }`.

Do **not** add `[data-zone]` colour rules yet — `lib/zones.ts` does not exist. P1.3 adds them.

**Done:** `npm run build` passes; the home page shows the gradient with no console error.

## P0.6 Fonts

**Files:** `app/layout.tsx` (font wiring only), `app/globals.css` (mapping).

`next/font/google`: `Inter` → `--font-sans`, `Instrument_Serif` → `--font-display`. Apply both as CSS variables on `<html className>`; map `--font-sans` to body and `--font-display` to headings. Remove the scaffold's Geist wiring — its `layout.tsx` imports and the `@theme inline` `--font-geist-*` mapping — or the text silently falls back to Arial.

`next/font` downloads at build time. If the build host has no network, swap to a system stack (`ui-sans-serif, system-ui, Georgia, serif` for display) and log a `DECISIONS.md` row. Do not vendor font binaries.

**Done:** `npm run build` passes; headings render in the display face; no layout shift on load (font variables are on `<html>`).

## P0.7 Playwright and pixel helper

**Files:** `playwright.config.ts`, `tests/helpers/pixels.ts`, `tests/shots.spec.ts`.

`playwright.config.ts`:
- `webServer` runs `npm run build && npm run start` (or reuse an existing one on CI), `baseURL: http://127.0.0.1:3000`, `reuseExistingServer: !process.env.CI`.
- projects: `chromium-desktop` (1280×720, `deviceScaleFactor: 1`) and `chromium-mobile` (390×844, `isMobile`, `hasTouch`).
- headless WebGL needs the software renderer:
  `launchOptions.args = ['--use-angle=swiftshader', '--enable-unsafe-swiftshader', '--ignore-gpu-blocklist']`.

`tests/helpers/pixels.ts` exports two functions only:
- `decode(png: Buffer): { width, height, at(x, y): [number, number, number] }` using `pngjs`.
- `meanLuma(img, rect?)` using WCAG relative luminance (sRGB → linear).

`tests/shots.spec.ts` screenshots scroll 0/50/100% at both projects into `qa/screens/`.

**Done:** `npx playwright test tests/shots.spec.ts` passes and writes six files to `qa/screens/`.
