**Goal:** the page is fast on weak hardware, readable without WebGL, and keyboard-complete.
**Read:** `SPEC.md` §1 (C5–C7), §3, §7; `skills/ocean-a11y-contrast/SKILL.md`.
**Exit:** Lighthouse (`?fx=off`) Performance ≥ 90, Accessibility ≥ 95, Best Practices ≥ 95, SEO ≥ 95; C5/C6/C7 tests pass; fallback screenshots saved.

## P6.1 Quality tiers

**Files:** `lib/signal.ts`, `lib/tuning.ts`, `tests/c7.spec.ts`.
Tier 0 full · Tier 1 adaptive-low (DPR 1, `uOct` 2, snow halved) · Tier 2 coarse pointer or `innerWidth < 768` (DPR 1, no snow/glow/ripple; springs stay on — **mobile is not reduced motion**) · Tier 3 reduced motion (static) · Tier 4 no WebGL2 or `?fx=off` (CSS only).
`tests/c7.spec.ts` unit-tests the tier decision as a pure function for each input tuple.
**Done:** `tests/c7.spec.ts` passes; forcing each tier in dev produces the expected canvas state.

## P6.2 Adaptive quality

**Files:** `lib/signal.ts`.
Rolling 2 s mean frame time, measured only after `T.warmupS`. If fps < `T.fpsLow` (30) → tier 1. Else if fps < `T.fpsMid` (45) → DPR `T.dprMid`. **Never upgrade mid-session.**
**Done:** a Playwright run with 4× CPU throttling lands on tier 1 and still renders.

## P6.3 Effects toggle

**Files:** `components/ui/EffectsToggle.tsx`.
A real `<button>` with `aria-pressed` and a visible label ("Reduce motion"). Initial state = `prefers-reduced-motion`; an explicit choice persists in `localStorage` and wins over the media query. Toggling must not remount `<main>`. This is the only way a user can reach reduced motion on a device that does not advertise it.
**Done:** toggling freezes/unfreezes the canvas, persists across reload, and is keyboard operable.

## P6.4 No-WebGL fallback

**Files:** `components/ocean/OceanCanvas.tsx`, `app/globals.css`, `tests/c6.spec.ts`.
No WebGL2, a `webglcontextlost` event, or `?fx=off` → do not mount a canvas. The static per-zone gradient becomes the background (each `[data-zone]` paints `--bg-top` → `--bg-bot`; Hero keeps its 30/70 split from P1.9). Every section, link, and form still works.
**Done:** `tests/c6.spec.ts` covers both fallback paths without a new Playwright project: (a) load `/` with `?fx=off`; (b) `page.addInitScript(() => { HTMLCanvasElement.prototype.getContext = () => null })` before load. In both, assert there is no `<canvas>`, all five sections and the contact form are present, and the C6 links still work.
