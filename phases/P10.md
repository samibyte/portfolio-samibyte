# P10 — Content in water (editorial redesign)

**Goal:** stop the page reading as a clean portfolio template over a very good animated background. This phase keeps the section order, the zone map and C1–C8, and redesigns the page as a water column: type sits on the water, a left dock replaces the top navbar, the hero name is a large extruded object resting on the 30% line, and the environment both lights the content and reacts to it.

**Owner decisions and defaults (2026-11-15):**
- **Editorial evolution, not a full restructure.** Section order, `data-zone` map, C6 destinations and the case-study route stay. The internal layout, typography, spacing and chrome are rebuilt.
- **Type on water, glass for instruments.** Prose, project content, journey and skills are set directly on the water. `glass()` stays for the dock, controls, fields, chips, the station plates and any floating instrument. This narrows D-202; it does not remove the glass system.
- **Remove the top navbar.** One fixed left dock replaces `Nav` + `DiveLine` + `EffectsToggle`. The left rail is the page's depth spine and defines the content gutter. Mobile defaults to the same left rail (44 px targets); the owner may still choose a bottom-left capsule before P10.0.
- **Bigger 3D masthead, variant A.** The name is real HTML set ~2.5× current size, with a CSS 3D extrusion, a per-letter wave, a submerged bottom edge and a masked reflection. It rests on the 30% waterline. No WebGL text, no font mesh, no new dependency.
- **Foreground occlusion is real.** A bounded, tier-0-only **2D** canvas above `<main>` draws bokeh, lens-wet streaks and one scripted silhouette. It is driven by the existing loop. It needs a C5/§3.13 amendment (owner action below).
- **Keep the 25 vh inter-section gaps.** Depth rhythm comes from per-zone section padding, not from changing `T.gapVh`. No §3.5 amendment.

## Locked constraints

- **C1:** the waterline stays at 30% at rest and moves 1:1 with scroll. The masthead composes around it; the mask is never moved by typography, the foreground canvas or any DOM transform. Boundary evidence is canvas-only and unchanged.
- **C2:** no foreground sprites, reflections or glows at 100% scroll. Every new layer fades with depth; abyss stays near-black and blue-dominant.
- **C3:** springs untouched. Content may read `signal.scrollSpring`; it must not change it.
- **C4:** all real text stays `var(--text)` and passes AA in its zone. Decorative copies (submerged edge, reflection, oversized `aria-hidden` watermarks) are not text evidence; the above-surface masthead copy stays non-`aria-hidden` so C4 measures it. No foreground sprite, gradient or blend may sit over a body-copy rect; the rects are uploaded to the shader/overlay as keep-out zones. Any overlay above text is capped at +0.06 luminance lift in dark zones.
- **C5:** native scroll only, one `requestAnimationFrame` loop in `lib/signal.ts`, no `preventDefault` on wheel/touch, no `transform` on `<main>`. The dock's motion is CSS transitions. The foreground canvas is 2D and loop-driven, never self-animated. The C5 amendment is a prerequisite, not a loophole.
- **C6:** Projects, Resume and Contact stay reachable at scroll 0 at 1280×720 and 390×844 with effects on and off. The dock carries the same `nav a[href="/"]`, `nav a[href="/#projects"]` and `nav a[href^="http"]` targets so the existing selectors keep working. Targets are ≥24×24 px (aim for 44 px). Focus is never obscured. The anchor test is rewritten to be orientation-agnostic (destination top in the first third of the viewport and the heading is the `elementFromPoint` hit), which is stronger than the old `sectionTop >= navBottom`.
- **C7:** the foreground canvas is tier 0 only; tier 1+ and reduced motion must not mount it. No second WebGL context. No animated `filter`, `backdrop-filter`, `box-shadow` or layout property. DPR ≤ 1.5 and a half-resolution backing store.
- **C8:** no copy changes. No invented depths, temperatures, pressures or dates. Station metadata comes from `lib/zones.ts` (`metersFrom`/`metersTo`/`label`) and from scroll position. Case is presentational (`text-transform`), never a rewrite.
- **No new dependency.** Fonts use the existing `next/font/google` path. One glass system, one loop, one shader.
- **Glass scope (after owner action):** `glass()` for the dock, toggle, station plates, chips, form fields and controls. No card fill, border or shadow around prose, journey, project content or skill text.

## Design contract

### Typography

| Role | Face | Use | Treatment |
|---|---|---|---|
| Display | existing display serif (revisit Fraunces only in P10.1 if the extrusion reads thin) | masthead, station titles, contact heading | `clamp(3.5rem, 10vw, 12rem)`; masthead `clamp(6rem, 16vw, 15rem)` desktop, `20vw` stacked mobile; leading `0.88–0.94`; tracking `-0.03em` |
| Instrument | one monospace via `next/font/google` | depth, index, dates, tags, dock labels, form labels, readouts | uppercase, `0.14–0.25em` tracking, tabular numerals |
| Body | existing sans | prose and descriptions | one step larger than today, measure ≤ 62ch, leading `1.65` |

Rules: `text-wrap: balance` on display, `font-optical-sizing: auto`, vertical `writing-mode` for station labels and journey years. Never animate `letter-spacing`, `font-size` or line-height per frame.

### Grid and rhythm

- 12-column full-bleed grid. Desktop dock gutter `4.5rem` collapsed; content starts after it and spans an asymmetric 6–9 columns. Mobile gutter `3.5rem`.
- Section padding per zone: surface `12vh`, sunlight `16vh`, twilight `20vh`, midnight `24vh`, abyss `28vh` (`--station-pad` on `[data-zone]`). Shallow feels tight; deep feels vast.
- Sticky station plates: `03 / SUNLIGHT / 30–200 M`, mono, native `position: sticky`. No scroll hijack.
- Negative space is water. Content hugs the gutter and the right edge; the centre is allowed to be empty.

### Section briefs

| Area | Brief |
|---|---|
| **Hero** | Masthead variant A (below). Role/location as a mono line in the sky; intro and CTAs below the line in the water. Buoy chip floats beside the name with a mooring line. One `aria-hidden` oversized "samibyte" watermark below the surface is allowed. |
| **Projects** | Strata, not a card grid. Sticky index at the left; full-width rows with a huge numeral, title, tagline and mono stack; architecture expands inline on focus/hover. Row light follows the pointer/caustics. |

### Masthead (variant A)

- Structure: `<h1 aria-label="Sami Adnan">` containing an **above copy** (not `aria-hidden`, measured by C4), a **below copy** (`aria-hidden`, the submerged sliver, `blur(0.5px)`, `scaleX(1.01)`, `color-mix(--text 92%, water-teal 8%)`) and a **reflection** (`aria-hidden`, `scaleY(-1)`, gradient mask ~8vh, `blur(2px)`, opacity ~0.15).
- Both copies sit in full-hero wrappers with fixed `clip-path` (`inset(0 0 70% 0)` above, `inset(30% 0 0 0)` below). The clip does not move; letters translate inside it, so lifted letters emerge and sunken letters submerge.
- Word box bottom: `calc(30% + var(--submerge))` with `--submerge: clamp(8px, 1.6vw, 20px)`.
- Extrusion: 6–10 static `text-shadow` layers down-right in a deep teal derived from `--text`; 4 layers on coarse/tier ≥2. Fill stays exactly `var(--text)`.
- Motion: `onFrame` per-letter two-sine lift, phase `0.45 rad` per letter, amplitude 7 px desktop / 4 px mobile, plus `scrollSpring.x × 3px`; adjacent letters differ ≤4 px. Pointer `rotateY` ±1.2° on fine pointers. Values rounded to `0.5px`, written only on change. No `setState`.
- One-time entrance: 40 ms stagger, fade + 12 px rise.
- Reduced motion: no writes; submersion, extrusion, reflection and tilt are static. Coarse: slow 4 px bob, fewer extrusion layers, no pointer tilt.
- Mobile: stacked `SAMI` / `ADNAN`, same baseline and submersion logic.

### Foreground atmosphere (2D)

- `ForegroundCanvas`: one `<canvas data-foreground-canvas>` above `<main>` (z-2) and below chrome (z-10), `aria-hidden`, `pointer-events:none`, 2D context only.
- Draws ≤8 soft sprites: 4–6 bokeh discs, 2–3 lens-wet streaks, one scripted silhouette at a fixed depth band. No water, no text, no background.
- Mounted only at tier 0 with effects on. Hidden for reduced motion, coarse pointer, tier ≥1, `?fx=off`, lost context and no-WebGL fallback.
- Half-resolution backing store, DPR ≤ 1.5, alpha ≤0.18, keep-out over body-copy rects. Fades to zero by the abyss.
- Driven by `onFrame`; no second rAF, no second WebGL context, no CSS animation.

### Two-way coupling

- **DOM → shader:** up to 8 `data-water-block` rects cached in `lib/layout.ts`, uploaded as `uniform vec4 uBlocks[8]` (nested array, constant loop). Particles and fauna dim/deflect near them; a soft meniscus forms at their edge. No new noise taps. Off at tier ≥2. Debug layer code `19` outputs the keep-out field.
- **Water → DOM:** `lib/signal.ts` exposes rounded environment values (depth, local light, current, flow phase). Consumers write CSS vars on themselves only, never `:root`/`body`, never per-frame `setState`. Use it for the dock depth needle, rule tilt (±0.6°), station-plate light and buoy line. Body copy never moves.
