## P2.1 `lib/layout.ts`

**Files:** `lib/layout.ts`.
Render-free module. `measure()` walks `[data-zone]` sections, caches `{ id, zone, pageTop, pageBottom }` in document order, then hands the offsets to `setSectionOffsets()` from `lib/zones.ts`. Call it on mount and from a `ResizeObserver` on `<main>` (rAF-throttled to one call per frame). Export `sections()`, `sectionAt(pageY)`, and `documentHeight()`.
**Done:** typecheck passes; a temporary `console.log` in dev shows five sections after load (remove it before commit).

## P2.2 `lib/signal.ts`

**Files:** `lib/signal.ts`.
Module singleton, no React. Holds `scrollY`, `scrollTarget`, spring value/velocity for scroll and pointer, `time`, `zone`, `reduced`, `coarse`, `webglOk`, `plungeStartedAt`.

- `stepSpring(x, v, target, dt)` — a **pure exported function**, so C3 can unit-test it. It returns `{ x, v }` (never mutates `T`):
  `s = dt * 60; v += (target - x) * T.springK * s; v *= Math.pow(T.springD, s); x += v * s;`
- `start()` / `stop()` — one rAF loop. It must be safe to call twice (React 19 StrictMode).
- Each frame: `dt = Math.min((now - last) / 1000, T.dtMax)`.
- Reduced motion: `time` frozen at 0, springs driven to 0, and the loop only writes when a value actually changed.
- `coarse` = `matchMedia('(pointer: coarse)').matches || innerWidth < 768`.
- Plunge: set once when `scrollY > 0.05 * vh`, but **not** if the page loaded already past it.

**Done:** typecheck passes; `stepSpring` is exported and has no DOM access.

## P2.4 `OceanCanvas`

**Files:** `components/ocean/OceanCanvas.tsx`.
`'use client'`. Client-only, dynamic import with `ssr: false`.

- Bail out (render nothing) when `?fx=off`, when `prefers-reduced-motion` is set **and** the user has not opted in, or when WebGL2 is unavailable. A coarse pointer still gets a canvas — it is Tier 2 (DPR 1, fewer layers), not reduced motion (D-012).
- `new Renderer({ canvas, dpr: Math.min(devicePixelRatio, T.dprMax), alpha: false, antialias: false, depth: false })`.
- `new Geometry(gl)` is not needed — `new Triangle(gl)` plus one `Program` (§6) and `new Mesh(gl, { geometry, program })`.
- Resize: `renderer.setSize(w, h)` with the active tier's DPR (`T.dprMax` full, `T.dprLow` Tier 1/2, `T.dprMid` adaptive). On coarse pointers ignore height-only changes under 120 px (mobile URL bar).
- Mount after first paint and fade in over 400 ms via CSS opacity, not a JS animation.
- Cleanup: cancel nothing (the loop is P2.2's), `program.remove?.()`, `geometry.remove()`, `renderer.gl.getExtension('WEBGL_lose_context')?.loseContext()`, `renderer = null`.

**Done:** canvas appears, no console errors, and unmount/remount (StrictMode) does not leak contexts — check `chrome://gpu`-free by counting `webglcontextlost` events in dev.

## P2.6 Uniform wiring

**Files:** `components/ocean/OceanCanvas.tsx`, `components/ocean/shader.ts`.
Per frame, before `renderer.render`:
- `uBg` — a persistent plain array of **five `[r, g, b]` triples**, filled in place each frame from `bgAt()` at viewport rows `scrollY + [0, .25, .5, .75, 1] × vh`, **from the top down**, so `uBg[0]` is the top row (the shader indexes top-first). It must be a plain `Array` of arrays, never a `Float32Array` — see `SPEC.md` §9.
- `uSky` = the `surface` zone's `bgTop`, `uAspect` = `w / h`.
- `uFx` — reals from `fxAt(scrollY + vh / 2)`.
- `uMouse` — `[x / w, 1 - y / h]`, init `(-1, -1)`. `uMouseVel` from the pointer spring.
- `uOct` — `T.octaves` normally, 2 in the low tier.
- `uTime` — `signal.time` (0 under reduced motion).
- `uRipple` — `T.ripple`, scaled by the pointer spring; 0 in Tier 2 and under reduced motion.
- `uDebug` — `0`; set `1` only while debugging the waterline mask.

Allocate the uniform objects and every array **once**, outside the loop; overwrite elements in place. OGL uploads on every `render`, so reusing the same nested array is safe.
**Done:** scrolling from surface to abyss changes the canvas colour continuously with no hard switch.
